# LPI reproducibility repository v1.0.0

Release date: 2026-09-15

## Scope

This is the first audited reproducibility release supporting the manuscript draft:

**A Laron inspired molecular state shows attenuated AKT mTOR signaling without targetable cancer vulnerability**

## Canonical results

- DepMap CRISPR: 914 solid-tumor lines, 20 lineages, 17,787 tested genes, 0 final-gate candidates.
- Fixed-seed CRISPR controls (`seed=20260915`): max-|t| empirical P = 0.056478; matched-random-signature empirical P = 0.960396.
- PRISM/GDSC pharmacogenomics: no replicated therapeutic-sensitivity signal; PRISM 0 global/0 family FDR signals, GDSC1 0/1, GDSC2 0/0.
- iLINCS: robust, node-specific perturbational connectivity; GHR/AKT1 and multiple PI3K/mTOR perturbations are LPI-concordant, while selected PIK3CB/PDPK1 perturbations are anti-concordant.
- TCGA: no pan-cancer proliferation association; lower purity-adjusted AKT-mTOR phosphosignaling at higher LPI.
- No target is eligible for docking or therapeutic nomination.
